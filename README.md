### Sobre o projeto

O projeto está disponível para visualização do código-fonte.

No momento, o sistema não está disponível para utilização no ambiente publico. Portanto, é possível consultar o código, mas as funcionalidades que dependem do backend e do banco de dados não podem ser testadas diretamente pelo site.
